# 차트와 화면의 인지 점검

사람은 화면을 감각(먼저 보이는 것) → 이해(무엇과 비교해 의미를 붙이나) → 기억(맥락과 함께 남기나) 순서로 받아들인다.

## 단계별 점검

| 단계 | 리포트(해석형) | 대시보드(요약형) | 표(탐색형) |
|---|---|---|---|
| 감각 | 제목과 요약이 맨 위에. 핵심 문장만 굵게나 색으로 | 핵심 숫자가 왼쪽 위(Z 순서). 강조는 한 곳 | 제목, 부제, 설명, 항목명, 값의 위계가 보인다 |
| 이해 | 차트마다 한 줄 설명. 데이터의 맥락(기간, 비교 대상) | 차트 하나에 질문 하나. 관련 지표끼리 묶음(근접, 공통 영역) | 의미 없는 선과 색을 뺀다. 관련 열끼리 가깝게 |
| 기억 | 결말(제언)이 있다. 이야기로 남는다 | 숫자마다 기준(전월, 목표). 덩어리 일곱 개 이하 | 좋고 나쁨의 맥락(전년 대비, 비중)을 표시 |

## 인지 위험 여덟 가지

| 위험 | 이런 모습 | 고치는 법 |
|---|---|---|
| 강조 남용 | 색, 굵기, 크기를 여러 곳에 동시에 | 중요한 하나만 강조. 나머지는 회색 |
| 시각적 편향 | 중요하지 않은 것이 가장 눈에 띈다 | 강조 세기를 실제 중요도에 맞춘다 |
| 시선 유도 왜곡 | 읽는 순서와 논리 순서가 다르다 | 결론을 먼저 보이게, 나머지는 논리 순서로 |
| 대표성 휴리스틱 | 그럴듯한 사례 하나로 전체를 말한다 | 사례 옆에 전체 숫자를 같이 |
| 가용성 휴리스틱 | 최근이나 강한 사례가 판단을 끈다 | 전체 기간과 빈도를 같이 |
| 앵커링 | 처음 보인 숫자가 기준이 된다 ("효과 +32%p") | 비교 대상과 상대적 의미를 같이 |
| 확증 편향 | 결론에 맞는 근거만 있다 | 반대 사례, 버린 설명을 같이 |
| 다크 패턴 | 축을 0이 아닌 값에서 시작해 차이를 키움, 단위를 바꿔 희석, 선택지를 불공정하게 배치 | 축과 단위를 정직하게. 막대는 0에서 시작. 선택지는 같은 무게로 |

## 판정을 적는 법

차트마다 "감각: 무엇이 먼저 보이나 / 이해: 무엇과 비교하나 / 기억: 맥락이 붙었나"를 한 줄씩 쓰고, 걸린 위험의 이름과 근거(어느 차트, 어느 부분)를 적는다. 이미지를 볼 수 없으면 차트 코드에서 축, 색, 제목을 읽는다.
