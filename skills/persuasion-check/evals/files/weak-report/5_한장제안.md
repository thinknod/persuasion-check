# 9월 매출 분석 보고

하루상점은 올해 1월부터 자사몰을 운영하면서 꾸준히 성장해 왔습니다. 그동안 여러 마케팅 활동과 사이트 개선을 해 왔고, 7월에는 무료배송 기준을 바꾸었으며 8월에는 SNS 광고를 늘리고 앱도 업데이트했습니다. 이번 보고서는 9월의 실적을 여러 각도에서 살펴본 것입니다.
